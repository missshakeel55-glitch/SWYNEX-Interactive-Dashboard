📊 **Amazon Product Analysis Dashboard | Power BI**

I’m excited to share my **Amazon Product Analysis Dashboard**, created using **Microsoft Power BI** as part of my journey in **Data Analytics and Business Intelligence**. 🚀

This project focuses on analyzing **product categories, pricing, discounts, ratings, and customer engagement** through an interactive and easy-to-understand dashboard.

🔍 **Key Analysis Covered:**
• Total and unique products
• Average product rating
• Average actual price
• Average discount percentage
• Product distribution across categories
• Discount group analysis
• Category-wise rating comparison
• Top products based on rating count
• Price and customer engagement analysis

• Microsoft Power BI
• Data Cleaning & Transformation
• Data Analysis
• DAX
• Data Visualization
• Dashboard Design
• Business Insights
